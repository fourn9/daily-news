参照元: Reuters (Diana Novak Jones) / Meta Newsroom / The Verge / WSJ

Meta Platformsは、Facebook/Instagramを「子どもを中毒化するよう設計した」「消費者を欺いた」等とする米国52州(48州+4司法管轄)の司法長官との一括訴訟について、最大$166.8億(約2兆6,500億円)を支払う和解に合意した(裁判所提出書類)。支払いは10年分割で各州の人口比配分。中身は10代ユーザーへの日次利用時間制限、アルゴリズムフィードの制御機能、独立第三者テストで偽陽性率10%以下を求める年齢確認基準の策定等の抜本的サービス変更を含む。全$166.8億のうち約$53億はTikTokおよびYouTubeが同種の対策を実装した場合にのみ満額支払われる条件付きで、業界横断の実質「ソーシャルメディア児童保護レジーム」化を狙う画期的合意。米大手テック企業の児童保護和解として過去最大級。

Amazon、DuckLabs(オランダ)を非公開額で買収　オープンソース列指向DB「DuckDB」開発チームがAWS入り、S3をストレージから「分析対象」化する戦略の要石に

参照元: GeekWire (Todd Bishop) / Slashdot / Techmeme

Amazonは26日、オープンソースの列指向分析DB「DuckDB」を開発するオランダAmsterdam拠点のDuckLabsを買収することで最終合意したと発表(取引額非公開、AWS部門で年内クローズ見込み)。DuckLabsチームはAWSに合流するが、DuckDBプロジェクト自体はMITライセンスの下、独立DuckDB Foundationの監督で引き続きオープンソース維持。AmazonにとってはS3を単なるストレージから、クラウドストレージ上のデータに対して直接高速SQL分析を回す「分析基盤」へ転換する中核ピースとなる。Motherduck(元Google DirectorのJordan Tigani氏創業)は「Amazonの伝統的な"OSSが成長したら競合サービス化"戦略の一環」と分析。買収を機にDuckDBのメンテナンスと機能拡張が加速し、Snowflake・Databricks・Google BigQueryへの直接的圧力となる可能性。

日本政府・日銀、株式/国債の即時決済へブロックチェーン基盤整備　日銀当座預金をトークン化=ホールセールCBDC、2030年代前半稼働・BIS「Project Agorá」の技術基盤へ

参照元: 日本経済新聞 (26日朝刊) / あたらしい経済 (Yahoo!経由)

日本経済新聞は26日、政府と日銀が、ブロックチェーンを用いて株式・国債の資金決済を24時間即時に完結する次世代決済インフラの整備に乗り出すと報じた。金融庁・財務省・日銀・金融機関による検討会を今夏立ち上げ、2027年初にも整備計画を取りまとめ、2030年代前半に稼働見込み。銀行が日銀に預ける当座預金の一部を「日銀当座預金トークン(=ホールセールCBDC)」に変換し、DLT基盤上で流通させる。現在T+2の株式決済・T+1の国債決済が即時化されれば、投資家は売却資金を即座に次投資へ回せる。BIS/IIFの「Project Agorá」(トークン化準備預金+商業銀行預金のクロスボーダー決済検証)の技術基盤としても機能する構想で、証券トークン化で先行する米欧・国際送金の次世代化で中国を巻き込む中東連携等に対する日本の巻き返しの一手。3メガバンク・大手証券の実証は既存進行中。

高市早苗首相は25日夕、記者団の質問に応じる形で、米国から制裁措置を受けた国際刑事裁判所(ICC)の赤根智子所長(日本人初の所長)について「守らなければならないし、ICCの最大資金拠出国として大切な組織も守っていかなければならない」と擁護方針を明言、"弱腰との批判は当たらない"と反論した。当初19日の外務報道官談話は「大変残念」との表現にとどまり、自民・中谷元前防衛相ら人権外交超党派議連が24日総会で「抗議も撤回要求もなく、欧州と比べ段違いに弱い」と突き上げていた。制裁は米入国禁止・米決済システム利用不可・米企業取引禁止(ICC別裁判官の"アマゾンAlexa反応せず"証言等生活影響あり)、赤根氏本人が日本時間26日午後にハーグからオンライン記者会見。プーチン氏・ネタニヤフ氏に逮捕状を出したICCの活動に対するトランプ政権の反発が背景。

続報米、22日発動のカナダ輸入品追加関税に、カナダは自動車等50%引き上げの報復措置を表明　日系自動車大手のカナダ生産拠点に直接影響、トランプ政権はオンタリオ湖の改称検討にも言及と対立激化

参照元: 朝日新聞 / NHK

米国が22日に発動したカナダ輸入品に対する追加関税に対し、カナダ側は自動車を含む一部品目で最大50%の関税引き上げによる報復措置を表明。日本の大手自動車メーカーはカナダに製造拠点を構えており、対米輸出向け生産分に関税が課される可能性が浮上、日系企業の連鎖影響が本格化する見込み。トランプ大統領はオンタリオ湖の"改称"検討にも言及するなど北米関係が異例の緊張に(NHK)。前日の"対カナダ車50%関税表明"(高市官民370兆円工程表と並列の外部リスク)から一段進み、日系企業の実損計上フェーズへ移行。日本政府は原油タンカー再保険の肩代わり法検討や9月原油調達を前年比8割へと、中東情勢とカナダ関税リスクを同時対処する総合政策パッケージを26日に決定。

トランプ政権、OpenAI/Google/Meta/Amazon等とAIの雇用インパクトを追跡する"データ共有契約"を締結　Zelenskyy大統領はUSK Musk氏にウクライナ最高章「自由の勲章」授与

参照元: Axios (Courtenay Brown) / Financial Times (Fabrice Deprez) / Techmeme

Axiosは26日、トランプ政権がOpenAI、Google、Meta、Amazonおよびその他大手テック企業と、AIが米国の雇用・採用に与える影響を追跡するためのデータ共有契約を締結したと報道。政府にAIプラットフォームの利用データや採用への影響情報が渡る形で、AI規制設計や労働政策の直接的インプットに使用される見込み。同日、ゼレンスキー大統領はイーロン・マスク氏に対しウクライナ最高栄誉章「自由の勲章」を授与、Financial Timesはマスク氏に対し「ロシア領内200km奥までStarlink利用を許可するよう要請したが、マスク氏はドローン攻撃への衛星利用を渋っている」と報道。テック各社と政府の関係性(米国は雇用データを取り、露宇戦線ではテック企業が事実上の"戦争実行資源"を握る)の非対称性が改めて浮き彫りに。
