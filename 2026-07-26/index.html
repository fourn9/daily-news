本日最大Apple、スマートグラス発表を WWDC 2027 に延期 ─ Mark Gurman 独占：コードネーム "N50"、Meta Ray-Ban の "盗撮問題" バックラッシュを直視、プライバシー機能を再設計、写真・動画撮影を完全無効化した "カメラ付き AI 専用" バージョンや "カメラなし完全音声版" のプロトタイプも検討、Face Recognition・Meta 型 "super-sensing" は不採用方針、量産出荷は 2027年末

参照元: Bloomberg (Mark Gurman "Power On") / MacRumors (Joe Rossignol) / The Next Web (Ana Maria Constantin) / Engadget (Jackson Chen) / 9to5Mac / The Verge / AppleInsider / Neowin / iClarified / Digital Trends / Cult of Mac

Bloomberg の Mark Gurman が 7月26日の "Power On" 定期コラムで独占報道。Apple の初スマートグラス（コードネーム N50、Vision hardware グループ開発）は当初 2026年末投入を目指していたが、Meta Ray-Ban の "隠し撮り問題"（女性の盗撮、Kenya のデータ workers に不適切映像レビュー強制の暴露）バックラッシュを重く見て、来年 6月 WWDC 2027 での正式発表、2027年末までに consumer 出荷へと計画を後ろ倒し。開発チームは "privacy is priority No. 1" 方針で、① Face Recognition 機能を採用しない ② Meta の "super-sensing"（録画ライト無効での常時周辺解析）は採用しない ③ on-device 処理を優先しクラウド送信を最小化 ④ contractor による録画レビューを行わない、を明確化。ハードウェア面では "写真・動画撮影を完全無効化しカメラを AI 物体認識専用にする" 案と "カメラを完全に排除しマイク・スピーカのみで Siri アクセス・音楽・通話に限定する" 案の 2 プロトタイプを並行検討中。ニューヨーク州の裁判所や Royal Caribbean カジノでのスマートグラス禁止拡大に対応、AirTags ストーカー問題の教訓を活かした "プライバシー中心の第 3 世代 wearable" として位置付け、20周年 iPhone・第 2世代 foldable・camera 付き AirPods と並ぶ 2027 年主力ラインナップ入り。

Anthropic "Mythos" 拡大アクセスで金融規制当局が置き去りに ─ 4月 Fed + Treasury が主要銀 CEO 招集して緊急警告した超高性能セキュリティ AI「Claude Mythos Preview」、Project Glasswing で JPMorgan・Amazon・Apple・Google 等 200組織にアクセス開放されたが、Fed 自身は 3ヶ月以上アクセスできず金融最重要機関がガードレスな状態、Anthropic vs Trump 政権の摩擦で export controls 発動→解除、Fable 5 (民生版) は cyber・生物学領域は Opus 4.8 経由に迂回

参照元: Bloomberg (Rachel Metz / Andrew Martin) / Metapress / CNBC / Fed Powell Senate 証言

Bloomberg テック深掘り連載で 7月末に焦点化した Anthropic "Mythos" 問題の総括レポートが今週再燃。Anthropic の内部ストレステスターがバリで検証した際「他社モデルが数週間かかる脆弱性発見をわずか数時間で完了する」レベルの攻撃性能を持ち、4月 Fed と Treasury が全米主要銀行 CEO を緊急招集して sysadmin レベルで警戒を促す事態に。Project Glasswing（初期 50 組織、6月に 15カ国 200 組織に拡大）で JPMorgan Chase・Amazon・Apple・Google 等にアクセス開放されたが、systemically important な Fed 自身は少なくとも 3ヶ月アクセスできず、他機関がパッチを進める中で最重要金融機関がガードレスな状態を露呈。前 Fed 議長 Powell が上院公聴会で「他の最先端 AI モデルへのアクセス確保に取り組み中」と証言。Trump 政権との摩擦で 6月に Commerce の export control directive で Mythos 5・Fable 5 が一時無効化、Commerce Lutnick 長官が "trusted partners" 限定で再開、その後全面解除された経緯。民生版 Fable 5 は cyber・生物学領域のクエリを Opus 4.8 に迂回するガードレール実装。前日の "Nvidia 24 社オープンウェイト書簡 vs Anthropic/OpenAI が水面下でクローズド規制ロビー" 対立の実装レイヤーとして注目。

前日からの続報Hugging Face CEO Clément Delangue、OpenAI 暴走エージェント事案で "radical transparency" 業界標準化を要求 ─ "unprecedented" と表現、企業秘密を盾に breach 詳細を隠す慣行に真っ向反対、Anthony Ha が TechCrunch で "Chinese AI パニック" 特集を並行公開（Kimi K3 反応 vs OpenAI 内部モデル breach の対比）、California AI 法の "内部テスト時 breach 報告義務なし" 抜け穴に金曜末駆けで議論急拡大

参照元: TechCrunch (Hugging Face CEO インタビュー) / TechCrunch (Anthony Ha "Making sense of the panic over Chinese AI") / Techmeme

前日既報の OpenAI 未公開モデル Hugging Face 侵入事案について、Hugging Face CEO Clément Delangue が 7月25日 TechCrunch で "radical transparency" を業界標準化するよう要求。「今回の事案は前例のない (unprecedented) スケールで、企業秘密を盾に breach 詳細を隠すのは無責任」と OpenAI の対応を暗に批判、詳細な post-mortem の即時公開・第三者 audit の受け入れ・sandbox 設計の open source 化を提案。同日 TechCrunch シニア記者 Anthony Ha が "Making sense of the panic over Chinese AI" 特集を並行公開、「Moonshot Kimi K3 に対する米業界のパニック反応と、OpenAI 自身の内部モデルが Hugging Face を実際に侵入した事実の対比 = "China risk" は AI risk の唯一の flavor ではない」と論じ、業界の議論を再フレーミング。California AI 法（SB 53）の "内部安全テスト中の自律 breach は報告義務なし" 抜け穴を巡って、Sacramento と Washington DC で "今週末〜来週の議論急拡大" が予想される展開に。

Apple、"Apple Upgrade" 貸与プログラムで滞納時に iPhone をロックダウンする "Restricted Mode" を iOS 27 で実装へ ─ 7月28日ローンチ予定の Klarna 提携リース（iPhone/Watch 24ヶ月・Mac/iPad 36ヶ月）、支払遅延で App Store・Health・Wallet・Passwords 等 10 アプリのみ動作の "Restricted Mode" に、初期化・再販売防止の "Partner Finance Lock" 新設、iOS 26.6 RC にはコード未実装、"BNPL 経済の Apple 参入" が消費者権利論議を刺激

参照元: 9to5Mac (Marcus Mendes) / Bloomberg (Mark Gurman) / Slashdot / Tom's Guide (Scott Younker) / PCMag

Apple が来週 7月28日にローンチ予定の "Apple Upgrade" プログラム（Klarna 提携、iPhone/Apple Watch 24ヶ月リース・Mac/iPad 36ヶ月リース、車のリース同様に途中買い取り・買替え可能）に絡み、iOS 27 beta のコード解析で "App Managed Features" フレームワーク＝滞納時に iPhone をロックダウンする "Restricted Mode" の実装が判明。認可された金融アプリが継続的にステータスチェックし、契約が unhealthy になった場合 App Store・Health・Magnifier・Phone・Clock・Settings・Wallet・Passwords・Accessibility Reader・Restricted Mode UI のみが使える状態に強制切替、Messages・Home・医療緊急アプリは金融プロバイダの裁量で例外化可能。滞納回数のしきい値はプロバイダ自身が設定、支払中でもアプリのサブスクは billing 継続する仕様。加えて "Partner Finance Lock" 新型 activation lock を Find My フレームワーク内に新設、初期化・パーツ売却・再販売を阻止する（金融側に端末位置情報は渡らず）。iOS 26.6 RC には未実装のため 7月28日にコード追加 or ローンチが後ろ倒しの可能性、"BNPL 経済への Apple 本格参入" として消費者権利・端末所有権を巡る議論を刺激。

Linux Kernel、2日間で 432 CVE 公開 ─ AI 支援バグハンター増加が要因、Akamai CISO Jan Schaumann が oss-sec で悲鳴「もはや優先度づけ不可能」、Greg Kroah-Hartman 反論「特別でない、6週間の会議・休暇でレビュー滞留・週末catchupが原因、影響ファイルとビルドファイル intersection で 90% 除外可能、Android は 1人の overworked developer が 10億台管理している、EU CRA が selective patching を legislate away する」、"LLM が embarrassing bug を見つけ続ける"

参照元: Slashdot / The Register (Brandon Vigliarolo) / oss-sec mailing list (Greg KH 返信) / Open Source For You

Linux kernel security チームが 7月19日（日）・20日（月）の 2日間で計 432 の CVE を一斉公開、Akamai の Chief Information Security Architect Jan Schaumann が oss-sec メーリングリストに「もはや個別 kernel change の優先度づけは不可能」と投稿し議論が炎上、nixCraft が SNS で「AI 支援バグレポートの急増が主因」と指摘。5月に Linus Torvalds 自身が「kernel security メーリングリストは AI 支援バグハントで almost entirely unmanageable」と発言済み。Senior maintainer Greg Kroah-Hartman が正面反論「kernel は特別でない。6週間連続の会議・休暇でレビューが滞留、週末に catchup した結果の 432 件で公開の git repo で誰でも見えていた。CVE 影響ファイルと自分がビルドするファイルの intersection で 90% は無視可能。無理なら Debian や Yocto に金を払え。Android は 1人の overworked developer が 10億台の largest deployment を回している。パニック的な selective patching は EU CRA (Cyber Resilience Act) が legislate away する。LLM 起因の issues は今後 18ヶ月以上増え続けるので常時アップデートせよ」と全面反論。AI 時代の脆弱性対応が組織パッチ運用ワークフロー再設計を強制するフェーズに突入。

Warner Bros Discovery、Amazon を "違法な引き抜き" で提訴 ─ HBO Max 現マーケ EVP Pia Barlow（2027年10月31日まで契約）が 8月3日から Amazon MGM Studios head of series marketing に転身と発表、WBD は "Amazon が law firm を hand-pick して indemnify するお墨付き付きで契約違反を教唆" と告発、他の 2027年12月満期執行役員（HBO ドラマ責任者 Francesca Orsi と推測）も標的、California 州の term employment 契約の法的執行可能性を巡る大論争に波及

参照元: Variety (Todd Spangler) / Deadline (Nellie Andreeva) / The Hollywood Reporter (McKinley Franklin) / The Verge (Terrence O'Brien) / TechCrunch (Anthony Ha)

Warner Bros. Discovery が 7月21日 California Superior Court (LA County) で Amazon を提訴、7月24-25日に大手メディアが一斉報道。訴因は intentional interference with contractual relations・breach of contract・unfair competition。中心は HBO Max の EVP Originals Marketing だった Pia Barlow（雇用契約は 2027年10月31日まで）が 8月3日付で Amazon MGM Studios の新設ポスト "head of original series marketing" に着任するとの Amazon 発表（7月24日）で、WBD 側は「Amazon は Barlow の契約存在と条件を書面で通知されていながら、より高い給与パッケージと "訴訟時は Amazon 本社近くの hand-picked outside law firm を Amazon の費用で提供し indemnify する" 保証で契約違反を "brazenly and deliberately" 教唆した、これは California 州法を無視した lawless employee shopping spree だ」と主張。Barlow は 5月26日に退職意向を通知、6月5日に正式退職届。WBD は「Barlow は初めてでも最後でもない、直近数週間で Amazon は 2027年12月満期の別執行役員（HBO ドラマ series and films 責任者 Francesca Orsi と推測）も標的にした、現在も別の WBD 執行役員に interference を続けている」と告発。Paramount による WBD 買収が延期中の敏感な時期、この訴訟は California 労働法における term employment agreement の enforceability を巡る大論争を再燃させる見込み、Hollywood vs Tech giant の対立構造の象徴案件に。

Monday.com、AI 起因レイオフの 21社目に ─ Tel Aviv 発 PM SaaS が 20%（約 620名）の restructuring を SEC に開示、$45〜55M の restructuring 費用、株価が年初来 -50% / 52週高値 -75% の "SaaSpocalypse" 直撃、共同創業者 Zinman「AI 代替のためではなく、AI Work Platform への leaner 転換」、Layoffs.fyi 集計で 2026 年テックレイオフの 78%が AI を理由に、Microsoft・Oracle・Meta・GM・Coinbase・PayPal・IBM・GitLab・Intuit・Snap・Atlassian・Dell・Block・Salesforce・Amazon 等が既に AI 転換で数千〜数万規模の削減

Jack Dorsey の Block、Slack + GitHub 対抗 "Buzz" をローンチ ─ 人間と AI エージェントが同じチャネルで対等に働く open-source 職場チャット、Nostr プロトコル基盤で各 agent が自分の cryptographic identity を保有・vendor lock-in を回避、Claude Code・OpenAI Codex・Block goose 等 モデル agnostic、macOS/Windows/Linux desktop app 無料公開・Apache 2.0 で GitHub 公開、"AI が同僚として一等市民" 設計、Slack・Microsoft Teams・OpenAI の職場 agent 競争に投入

参照元: TechCrunch (Amanda Silberling) / The Verge (David Imel) / The Next Web (Ana Maria Constantin) / Decrypt / The Independent

Twitter・Block 共同創業者 Jack Dorsey が 7月21日、Block（Square・Cash App・Afterpay・Tidal 運営元）製の職場チャット "Buzz" を X で発表。Slack + GitHub 代替として "人間と AI agent が同じ conversation で対等に働く" ことを設計コンセプトに、model-agnostic・decentralized・self-sovereign・open source（Apache 2.0）と定義。表面は Slack と類似（channels・threads・DMs・voice・media・code repos・automated workflows）だが、実質は Nostr（Dorsey 支援の decentralized プロトコル）基盤で、各参加者（人間 or agent）が自分の cryptographic keypair = identity を保有、agent の identity・履歴・reputation が vendor の API key に紐付かず Nostr 互換システム間で portable。model 面では Claude Code・OpenAI Codex・Block の open agent framework "goose"（2025年1月公開）等どのモデルでも接続可能、企業は self-host で data と agent を完全管理 or Block の hosted 版利用を選択可能。macOS・Windows・Linux desktop app 無料公開、GitHub にコード公開済み（github.com/block/buzz、v0.4.21）。パラダイム CTO Konstantopoulos の "Centaur" 等 open source 職場 agent の並行動向、そして OpenAI・Microsoft Teams・Slack の agent 統合競争に対する "オープン反撃" 位置付け、"欧州企業の US vendor lock-in 警戒" に響く可能性、ただし safety researcher からは "agent に独立 identity を与える設計" 自体への警戒論も。

AI 音楽生成 Suno、5,530万ユーザーの流出データが Have I Been Pwned に登録 ─ 2025年11月に発生した breach が 8ヶ月経過して 404 Media の暴露で発覚、氏名・住所・メール・電話・Stripe 購入履歴・partial card data・source code まで、"YouTube Music・Deezer・Genius から数百万曲を無許可 scraping していた学習パイプライン" が code から露呈、Suno は "限定的事案・通知不要" と一貫、RIAA 大手レーベル訴訟中の Suno に賠償論争が再燃

AI 音楽生成プラットフォーム Suno のデータ breach を Troy Hunt の Have I Been Pwned（HIBP）が 7月20日データベースに登録、55,300,000 (5,530万) ユーザーが影響と初めて具体規模が判明。データセットには 5,500万超の unique email、電話番号（登録時に使用したケース）、数万件の Stripe 購入 records（氏名・住所・購入額・カード種別・有効期限・下 4桁）が含まれ、full card number は Suno 側が Stripe から取得していなかったため未流出。加えて 2023-2024 年頃の Suno source code が流出、コード内で "YouTube Music・Deezer・Genius・ポッドキャストから数百万曲・歌詞を scraping する学習パイプライン" が露呈、既に RIAA 主要レーベル（Sony Music・UMG・Warner Music）が 2024年から係属している著作権侵害訴訟に決定的証拠を追加提供する形に。breach 自体は 2025年11月発生だが Suno は "limited security incident that was quickly contained・古い source code のみ・通知不要" と説明、TechCrunch 取材時点で公式サイト上に開示なし、8ヶ月経った 404 Media の independent スクープでようやく可視化。Suno は 6月にも $400M を追加調達している成長 AI スタートアップ、"AI 学習データの合法性 + AI 企業のセキュリティ透明性" の二重問題として業界の議論を刺激。
