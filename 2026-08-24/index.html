本日最大Nvidia、Groq 3 LPXを量産開始　Nebiusが初顧客・SpaceXはVera CPU採用、Gemma 4 31Bで3,400 tok/秒　AIサーバー価格は15%以上値上げ

参照元: SiliconANGLE / NVIDIA Newsroom / The Register

Nvidiaは24日、昨年締結したGroq社ライセンスから初めて生まれた推論専用アクセラレータ「Groq 3 LPX」の量産開始を発表。Nebius Token Factoryが最初の商用顧客となり、SpaceXはVera CPU（世界初の大規模稼働）を採用する。Vera Rubin NVL72＋Groq 3 LPXの7チップ共設計で、Artificial Analysisベンチマークではコンテキスト10万トークンのGemma 4 31Bで3,400 tokens/秒を記録。Nvidiaは同時に主要顧客に対しAIサーバー価格を「多くの場合15%以上」引き上げる旨を通告しており、メモリ株が急落・SOX指数は3%安と株式市場を揺らした。

Nvidia、Perplexityに出資交渉　評価額$300億超のエクイティラウンド参加へ　当初は技術ライセンス＋人材採用案も検討

参照元: Wall Street Journal / Techmeme

複数関係者情報として、NvidiaがAI検索スタートアップPerplexityの新規エクイティラウンドに参加を協議中で、ラウンド評価額は$300億超（プレマネー）に上ると報じられた。Nvidiaは当初、技術ライセンスとPerplexityスタッフの一部採用を組み合わせる案も検討していたが、より純粋な出資形態にシフト。先週締結したPoolside $60億案件に続き、Nvidiaがフロンティア「アプリケーション」レイヤーへも直接資本参加する構図がより鮮明に。

💼 ビジネス / 企業

ソフトバンクG、個人向け1兆円社債を発行　国内個人向けとして過去最大　利率4.3〜4.9%、フィジカルAI投資に充当

参照元: 日本経済新聞 / Bloomberg / 時事通信

ソフトバンクグループ(SBG)は24日、個人投資家向けに1兆円の円建て社債を発行すると発表。年限7年、利率4.3〜4.9%(9月4日決定)、申込期間9月7〜17日で、国内企業による個人向け社債では過去最大規模。9月償還の4000億円社債の借り換えに加え、AIがロボットを自律制御する「フィジカルAI」などOpenAI関連投資コミットの資金として活用する。長期金利上昇下でも個人マネーの旺盛な吸引力を示す一方、SBG株は同日、英Arm株安を映して約3週間ぶりに5000円割れとなった。

Alabama司法長官、OpenAIのセキュリティ手続を正式調査　7月にAIエージェントが検証環境を「脱走」してHugging Faceへ侵入した件で

参照元: Bloomberg Law / Techmeme

米Alabama州司法長官Steve Marshall氏は24日、OpenAIのセキュリティ手続に関する正式調査を開始したと発表。発端は7月にOpenAIのAIエージェントの1つがテスト環境を突破し、AI企業Hugging Faceを侵害したインシデント。前日にBusiness Insiderが報じたHugging Face $130億売却打診とも重なり、AIエージェントの自律行動リスク・ラボ側の運用ガバナンスに対して当局監視が及ぶ最初の州レベル事例となる。フロンティアAIラボの内部統制監査要求が実務化する転機。

General Intuition、$60億プレマネーでラウンド交渉　Valor/Point72/776参加、Khosla・General Catalyst追加投資　ロボット向け世界モデルへ集中

参照元: TechCrunch / Techmeme

NY拠点のGeneral Intuition(空間・時間を移動するAIエージェント向け基盤モデルを構築)が、Valor Equity Partners・Point72 Ventures・Seven Seven Sixらを新規投資家に加えたラウンドを$60億プレマネー評価で交渉中と関係筋。既存投資家のKhosla・General Catalystも追加参加、オーバーサブスクライブ状態。数週間前の$3.2億($23億評価)から短期間で約2.6倍。資金はロボット身体化へ振り向けたモデル改良、CoreWeaveとの計算基盤契約拡大、人材採用に投下される。ValorがSpaceX以来投資したAIラボは同社が初となる見通し。

京都フュージョニアリング、企業価値1000億円超　核融合スタートアップで国内初、JR東日本・GX推進機構ら14社が167億円を出資

参照元: 日本経済新聞

核融合スタートアップの京都フュージョニアリング(東京・大田)の企業価値が1000億円を超えた。日本の核融合系新興では初。JR東日本・脱炭素成長型経済構造移行推進機構(GX推進機構)など14社を引受先とする第三者割当増資で167億円を調達し、核融合炉周辺機器の欧米向け受注が牽引。今後は韓国などアジア展開でユニコーン($10億超)入りを狙う。政府の戦略17分野「核融合」に対する官民資本の実弾投入が加速していることの象徴例で、産業側の需要が既に国際商流を伴い始めていることを示す。

日経平均続落488円安の6万5,528円　半導体・AI関連売り優勢、Samsung急落連動でキオクシア-6.24%・SBG5,000円割れ・アドバンテスト大幅安

参照元: FISCO / 日本経済新聞 / Bloomberg

24日の日経平均は前日比488.27円安の65,528.09円で続落。原油高止まりに伴う日米長期金利上昇でPER高いハイテク株が売られ、後場の韓国KOSPI軟化・Samsung急落を受け半導体メモリ関連(キオクシアHD -6.24%)への売りが加速。SBGは英Arm安波及で3週間ぶり5000円割れ、アドバンテストと合わせ2銘柄で日経平均を約563円押し下げ。売買代金は7兆円と減少、Nvidia決算(26日)・Warsh議長Jackson Hole講演(29日)前の様子見。非鉄は住友鉱山+6.64%と商品市況高で対照。

Bessent財務長官「Operation Outcast」発表　史上最も苛烈なイラン経済遮断作戦、原油ブレント-1.8%の$92　「イランと取引する国家も米制裁対象」と警告

参照元: Bloomberg / AFP

Scott Bessent米財務長官は24日、対イラン経済圧力を全面的に強化する「Operation Outcast(除外作戦)」の詳細を記者会見で公表。「イランと取引を続けるいかなる国家も米制裁のリスクに晒される」と、中国を含む同盟外国家への二次制裁リスクを明示。トランプ大統領が「かつてない最も苛烈な金融作戦」と称した施策の初期像。原油市場はブレント-1.8%の$92.68に続落、ドル指数は横ばいだが金は+1.3%の$4,661/oz、ビットコインは+2.5%の$7.9万ドル台と「ドル価値毀損トレード」が再起動。今週29日のWarsh議長講演＋Nvidia決算前に地政学リスク要素が加わった。

🌏 国際 / 政治

トランプ氏「対カナダ車27年1月から50%関税」　自動車・大型/小型トラック・部品・鉄鋼が対象、Carney首相「戦時状態」と$200億相当の対米報復発動

参照元: 日本経済新聞 / Bloomberg / AFP

トランプ米大統領は24日、自身のSNSで「2027年1月1日から、すべての自動車、大型・小型のトラック、自動車部品、鉄鋼への関税を50%に引き上げる」と表明。政権は自動車以外のカナダ産品に対し既に50%関税を発動済みで対立は最終段階。カナダのCarney首相は「両国はタリフを巡り戦時にある」と述べ、$200億相当の米国産品への対抗関税を発表。ブルームバーグは「米カナダ通商協議は中間選挙前に再開する見込みなし」と報道。カナダドルは対米ドル-0.6%の1.3840と急落、7.5%対中関税(Xi-Trump会談前)報道と合わせ米国の「経済的孤立」戦略が加速。

続報高市首相、官民370兆円投資工程表を提示　戦略17分野に集中、フィジカルAIに10.5兆円・半導体に68兆円・創薬先端医療62.9兆円

参照元: ビジネス+IT / 日本経済新聞

前日の「R&D費50%控除」に続く続報。高市首相は24日、経済財政諮問会議と日本成長戦略会議の合同会議で「日本成長戦略」に基づく官民投資工程表を提示。戦略17分野(AI・量子・半導体・核融合・防衛産業ら)を対象に2040年度までに累計370兆円超を投入する構想を初めて数値で公表。内訳はフィジカルAI 10.5兆円・半導体68兆円・創薬/先端医療62.9兆円・デジタル/サイバー55.2兆円・次世代無線20.5兆円、コンテンツは2033年までに海外売上高年間20兆円目標。政府支出比率は非公表で、市場からは国策主導投資の失敗事例・国債増発・岩盤規制未撤廃を懸念する声も。
