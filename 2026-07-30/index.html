本日最大Microsoft FY26 Q4、Azure が年間 $100B を初突破 ─ 四半期売上 $90B (+18% YoY)・EPS $4.74・純利益 $36B、Azure 単四半期 +43% ($124B ラン・レート)、Microsoft Cloud $59.3B (+27%)、Copilot 有償席数 3か月で 20M → 30M と 50% 増、Commercial RPO $678B (+84% YoY)、通期売上 $331B・営業利益 $155B、Capex 単Q $41B (+70%)・FY27 も加速維持、株価 AH で +9%、"Anthropic 投資評価益なしでも EPS $4.39 で市場予想 $4.29 超"、Meta 決算 (Reality Labs $4.6B 赤字・株 -11%) と対照的な "AI 投資の勝ち組"

Microsoft が 7月29日 (現地時間・日本時間 30日朝) に FY26 Q4 (2026年4-6月) 決算を発表、四半期売上 $90.0B (市場予想 $87.62B 比大幅超過・+18% YoY)、純利益 $36B (+31%)、EPS $4.74 (予想 $4.22)、Azure 及び他のクラウドサービス売上が +43% (前 Q の +40% から加速) と "capacity timing の逆風" を跳ね返して市場予想 40% を上回った。Satya Nadella CEO 「Azure の年間売上が初めて $100B を超え、Microsoft 365 Copilot は 30M 以上の有償席に到達 (前 Q の 20M+ から 3か月で 50% 増)、AI トランスフォーメーションを牽引する当社への信頼の証」とコメント、Microsoft Cloud 通期 $214B (+27%)、通期売上 $331B (+18%)、通期営業利益 $155B (+21%)、Commercial RPO (契約バックログ) は 5四半期で倍増して $678B (+84% YoY)。Capex は単四半期 $41B (+70% YoY) で、FY26 通期 Capex 見通しを従来の $190B から $175B に会計変更で下方修正しつつ "支出計画は不変"、Amy Hood CFO 「H1 の Azure 成長は加速する、FY27 も CF は継続して十分に強い」と発言。市場は AH で +8-9% で反応、時価総額は Meta 決算 (revenue +28% $60.8B・profit -14% $15.8B・Reality Labs 単Q -$4.6B・株 AH -11%) と対照的、"Anthropic への出資評価益を除いても EPS $4.39 で予想 $4.29 超" (M Mohan/Mukund の分析) と "地力の強さ" が確認され、Meta の "AI capex $130-145B に増額・Zuckerberg 個人的な賭け"、Nadella の "swappable AI models (MAI + Maia chips) を語り自社モデルへの独立性を強調" というポジショニングの違いが Big Tech Q2 決算の "AI 投資 ROI 差" の分岐点として業界で話題に。GitHub Copilot は 6月のプライシング変更 (usage-based) 以降の消費が想定超で寄与、"AI が Microsoft の収益に実利をもたらしていることが証明された最初の四半期" (Emil Protalinski / LinkedIn) との評価。

Meta Q2、AI 支出加速で市場失望 ─ 売上 $60.8B (+28%)・純利益 $15.8B (-14%・訴訟費用 $2.4B と人員削減費用が響く)、Reality Labs 単Q -$4.6B の赤字、AI Capex $130-145B (前四半期の $125B から増額)、フリーキャッシュフロー $784M (5年ぶり低水準)、株 AH -11%、Zuckerberg「5年以内に何十億人が personal AI agent を持つ」「Muse Spark 1.1 と Muse Image を出荷、Meta One サブスク開始」、BlackRock との infra 提携で調達手段拡大、Emarketer 分析「Meta は独自レーンを切り出そうとしている」

Meta Platforms が 7月29日 Q2 決算を発表、売上 $60.8B (+28% YoY・市場予想上回る)、純利益 $15.8B (-14% YoY・legal & severance charges で費用 +55%)、Reality Labs 部門は単四半期で $4.6B 超の赤字、キャッシュフローは $784M と 5年ぶりの低水準。株は AH で 11% 下落、投資家は "AI capex が上振れているのに OK 収益" に不満、Meta は 2026年通期 Capex を従来の $125B から $130-145B に上方修正 (Zuckerberg「AI 支出は core business の全部を加速している、企業向け販売も始める」との説明)、通期費用見通しは $165-169B に上方修正 (訴訟 $2.4B 込み)、Q3 売上ガイダンス $61-64B。BBC「投資家は AI プロジェクトへの支出継続の promise に反発、"personal agents will be next wave of our product line in months and years" "soon we'll have agents that work 24/7 on your behalf" と Zuckerberg は打ち出したが、そうしたビジネスは未実現」。Meta Superintelligence Labs から Muse Spark 1.1 (agentic coding model・computer use・tool use・multimodal に強い) と Muse Image (画像分析→広告バリエーション生成) を出荷、Meta AI 日次アクティブは Muse Spark 統合後に +60% と発表、Meta One サブスクも開始。BlackRock との infra 提携 (7/28 発表) で資金調達手段を多様化、"the industry has under-built for AI adoption, existing capacity extremely valuable" と Q2 と Q3 のキャパ最大化に注力。Zuckerberg は WSJ に "AI may deliver personal superintelligence to everyone" と op-ed を寄稿・"we're the only major company building AI with the primary goal of putting superintelligence directly into people's hands (not centralizing it)" とポジショニング。Meta と Microsoft の対照的な決算 (同日 MSFT +8-9% vs META -11%) が "AI 投資 ROI の差" を象徴、8月上旬の Apple・Alphabet・Amazon 決算に注目が集まる。

Zoox、NHTSA から Part 555 商用免除取得で有償ロボタクシー参入 ─ ステアリング・ペダルなしの purpose-built 車両で "初の商用免除" 事業者、来月から Las Vegas で有償運行開始、その後 California は PUC・DMV の別途認可待ち、年間 2,500 台 (2年間) の上限で "enhanced, adaptable oversight" 条件付き、CEO Aicha Evans「autonomous 車両にとって重要なマイルストーン」、Amazon は Silicon Valley 近郊工場で年 10,000 台の生産を計画し Waymo に挑戦、Waymo の高速道路サービス再開 (前日既報) と並び "AV 商用化 2波目" が同週に集中

参照元: TechCrunch (Kirsten Korosec) / AP News / CNBC (Annie Palmer) / WIRED (Aarian Marshall) / Zoox プレスリリース / NHTSA 連邦公報

Amazon 傘下の autonomous vehicle 企業 Zoox が 7月30日、米連邦道路交通安全局 (NHTSA) から Part 555 の "temporary exemption" を取得したと発表、ステアリングホイールもブレーキペダルも装備しない purpose-built ロボタクシーとして "初めての商用免除" となる。同社は 2025年8月に "public roads での実証と無償ライド" 免除を受けて Las Vegas・SF で無償の driverless サービスを提供していたが、有償化に必要な最終規制ハードルをクリア。免除条件は「年間最大 2,500 台を 2年間、enhanced adaptable oversight structure に従う」、Zoox スポークスパーソン「来月から Las Vegas で有償ライドを開始、追加市場は州レベルの commercialization 要件クリア次第で拡大、California では PUC (Public Utilities Commission) と DMV の driverless deployment permits が別途必要」とコメント。Aicha Evans CEO「autonomous 車両業界にとって重要なマイルストーン」と声明、Amazon は Silicon Valley 近くの工場で年 10,000 台のロボタクシー生産を目指し Alphabet 傘下 Waymo (2026年末に週 100万有償ライド目標) に挑戦する構図。NHTSA の Jonathan Morrison 管理官「autonomous 車両の安全な発展のために道を開きたい」、先月にはロボタクシーが brake pedal 無しで運行することを許可する新規則も提案中 (審議中)。前日既報の Waymo 高速道路サービス 2ヶ月ぶり再開 (Phoenix→LA・SF Bay Area) と重なり、"US AV 商用化 2波目 (Waymo 復帰・Zoox 参入)" が同週に集中、Kevin Mullin 議員の AV Emergency Response Coordination Act と並行して、規制と商用化が緊張感を持って進行するフェーズに。

FTC、Hims & Hers を提訴 ─ 患者の医療情報を Meta・Snap・Microsoft・Google・Pinterest・Reddit・X の広告 pixel で無断共有と主張、Utah・California 州も参加、"privately に扱う" と広告した性 wellness・肥満・メンタルヘルス処方薬販売の telehealth プロバイダが実は tracking pixel でユーザー行動を第三者に送信、キャンセルしにくい定期課金 (ROSCA 違反疑い)・intake 送信直後の課金など deceptive billing 3点セット、FTC 委員会は 2-0 で提訴決議、Hims & Hers 「baseless、3年間の調査で提出した証拠を無視」と反発、GoodRx・BetterHelp・Cerebral・Monument に続く "telehealth 版 HIPAA 空洞化" 訴訟 4社目、AI × 個人データ規制の週として印象付ける展開

参照元: TechCrunch (Zack Whittaker) / FTC プレスリリース / CBS News / MedTech Dive (Jill Hughes) / TheNextWeb (Ana-Maria Stanciuc)

米連邦取引委員会 (FTC) が 7月29日、Utah・California (LA County Counsel 経由) 州とともに、telehealth 大手 Hims & Hers を Northern District of California の連邦裁判所に提訴、性 wellness・肥満・メンタルヘルス・脱毛の処方薬販売サイトが 「privacy を守る」と広告しつつ、実際には Meta・Snap・Microsoft・Google・Pinterest・Reddit・X が提供する pixel-sized tracker で顧客の医療情報 (訪問行動・"Events") を第三者に共有していたと主張。加えて (a) medical provider と consult する前に処方料金を課金・(b) 定期サブスクをキャンセルしにくくする Restore Online Shoppers' Confidence Act (ROSCA) 違反疑いの 2点も列挙。委員会採決は 2-0 で提訴決議。Christopher Mufarrige (FTC 消費者保護局長)「消費者が知らずに定期課金に閉じ込められ、最もプライベートな医療情報を同意なしに第三者へ開示されるという問題ある scenario」と声明。Hims & Hers は「baseless、FTC が 3年間の調査で当社が提出した証拠を無視、法律を歪めて主張を作り出そうとしている、当社は反論する」と全面反論。過去に FTC は同じ pixel-based leakage で GoodRx・BetterHelp (BetterHelp は Facebook への患者データ共有で 2023年に禁止処分)・Cerebral ($7M 和解)・Monument (アルコール回復) を摘発してきた延長線、"HIPAA が広告依存アプリを想定していない法制の穴を消費者保護法で埋める" 継続戦略、Meta・Snap は被告ではないが "広告 pixel エコシステム自体が health data の leakage 装置" として名指しされる形。7/28 の Apple Upgrade Restricted Mode (前日既報) と並び "個人データ・プラットフォーム規制" のフェーズが July 末に集中。

英国 AI neocloud プレイヤーの Nscale が 7月30日、Anyscale の買収に $1.65B (Bloomberg 匿名 source) で合意したと発表。Anyscale は Ray (Python 分散処理・LLM 訓練・強化学習・data curation・inference の open-source フレームワーク) 開発チームによる compute scaling プラットフォーム企業、Coinbase・Bedrock Robotics・Runway 等の AI プロダクション顧客を抱える。Nscale は「電力・データセンター・GPU・orchestration ソフトウェアに続き workload scaling までを垂直統合、"first full-stack AI hyperscaler" を目指す」とポジション。Josh Payne CEO (Nscale)「他の infrastructure provider は GPU を買って貸すだけ、当社は power・data centers・compute・software の全レイヤーを自社所有・自社構築する、Anyscale で AI teams が任意ワークロードをスケールする managed services が完成、vertically integrated AI cloud platform になる」、Keerti Melkote CEO (Anyscale)「Ray に基づく当社プラットフォームと Nscale の data centers・compute・AI cloud services が結合、より大規模・低コストで任意 AI workload を実行できる企業が増える」。Anyscale ブランドは独立継続、200名の従業員 (米国・欧州・India) 全員が Nscale に加入。買収は 2H 2026 に規制承認とクロージング条件を経て完了予定、Microsoft Azure ラン・レート $124B、Meta の Capex $130-145B、CoreWeave・Lambda・Crusoe 等の neocloud 群の中で Nscale が "垂直統合 hyperscaler" 化を先行させる construct、"AI インフラ再編" の週にもう 1本柱を追加。
