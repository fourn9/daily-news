本日最大Slack、AIコーディング専用チャネル「Slack Code」全プランで一般提供開始　Claude Code・Devin・Copilot・Codex・Vercel Agentが「チームメイト」として参加

参照元: Slack Blog / The Verge / The Next Web / Unite.AI / RuntimeWire

Salesforce傘下Slackは20日、プロジェクト単位でAIコーディングエージェントとチーム協業する新機能「Slack Code」を全プラン（無料含む）で一般提供開始。ユーザーが会話内で@Claude / @Devin / @Copilot 等をタグすると、そのエージェントが専用の「code channel」を自動生成し、チーム全員がコード差分・HTMLプレビュー・レビュー・承認を同一チャネル内で完結できる（完了で自動アーカイブ・監査ログ保持）。ローンチパートナーはAnthropic Claude Code、Cognition Devin、GitHub Copilot、Vercel Agent、OpenAI Codex。「Add to Slack」フローでLovable・n8n・LangChain・Superhuman等も数クリックで追加可能。Anthropicの6月「Claude Tag」の自然な延長で、Salesforce Agentforceと外部AIエージェントの共存路線が鮮明化。「vibe coding」を個人作業からチーム競技へ転換する試みとして、企業のSlack内AI予算の主戦場となる可能性がある。

Waymo、自社製5nm ASICを初公開　1,000 TOPS前処理・第6世代Ojaiに搭載、AMD・Nvidia・TSMC等7社の供給網も開示

参照元: The Verge / Bloomberg / TheNextWeb / Yahoo Finance

Alphabet傘下Waymoは20日、ロボタクシー用に自社設計したTSMC 5nm製ASICを初公開した。カメラ13台＋4LiDARの生センサーデータをコアML推論エンジンに渡す前段の前処理・センサーフュージョン・低照度時のtemporal denoisingを担い、単体で1,000 TOPS超（Nvidiaの自動運転向け最新システムに並ぶ水準）を発揮。Zeekr製の第6世代車「Ojai」約300台に搭載済みで、LA・Phoenix・SFで19日から一般向け配車開始（デンバー・ラスベガス・サンディエゴ年内展開予定）。供給網はAMD・Micron・Nvidia・Samsung・SanDisk・Socionext・TSMCと初公開、Nvidia・AMDからの脱却ではなく「MLファースト・アーキテクチャの一部として補完」と位置付け。Alphabetの前日Marvellワラント（＄12.2B）と併せ、Google経済圏のカスタムシリコン戦略が自動運転にまで波及した形。第6世代の車両単価は$20-25K（第5世代$100-125Kから大幅低減）と推定される。

Anthropic、8月末にもIPO正式申請へ　SpaceX $86.2Bの史上最大記録の同等以上を目標　CEO超議決権株検討

参照元: Bloomberg / QZ / Crypto Briefing / TradingKey

BloombergはAnthropicが月末にもS-1を公開提出しIPOを本格始動、SpaceXの史上最大記録$75B（オーバーアロットメント込$86.2B）と同等または上回る調達を目標としていると報道。6月にS-1 draftをSECに機密提出済み、Morgan Stanley・Goldman Sachs・JPMorganが主幹事。CEO Dario Amodei・共同創業者に強い議決権を与えるsuper-voting株の導入を検討中。IPO前に当初想定$10Bを大幅超過する revolving credit facilityの締結も予定。Q2売上$11.5B・年換算$25億超のClaude Code貢献で四半期adjusted営業利益は黒字転換、エンタープライズLLM APIで32%シェア（首位）を確保。8月14日Reuters報道の2028年売上見通し$190-200Bを軸に、Cloudflare・Palantir・SpaceXがEV/売上倍率のベンチマーク。OpenAIは2027年公開に後ずれ観測、Anthropic先行公開でAI銘柄への資金流入拡大が視野に。もし$86.2B超なら2026年米IPO調達額が2021年ピーク$195.2Bを上回る歴史的高水準に到達する。

Nvidia、中国専用LPU推論チップを年内出荷へ　昨年12月Groqとのライセンス契約由来、H200と並行して輸出規制準拠

参照元: The Information / Wccftech / Tom's Hardware

The Informationは20日、Nvidiaが2025年12月に締結したGroqとの技術ライセンス・人材/資産移管契約を基に、中国顧客向けにGroqのLPU（Language Processing Unit）アーキテクチャを流用したAI推論専用チップを年内小ロット出荷開始すると報道。米輸出規制（HBM容量・CoWoS等の先端パッケージ制限）に準拠する設計で、SRAM 230MBに重みを焼き付けキャッシュを介さない超低レイテンシ推論を狙う。北京がH200輸入を実質阻止し（ByteDance・Tencentは各1万個受領も本土持ち込み制限）、SMICの7nm独占（稼働率93.7%）でNvidiaの中国売上が構造的に縮小する中、「規制と地政学の狭間で中国基盤を維持する」現実解として提示された格好。Nvidiaの中国戦略は次期Xi訪米（9月予定）を控え、H200正規ルート＋LPU派生チップの二本立てへ再編される。

モデルナ・メルクのmRNAがんワクチン、悪性黒色腫第3相で有意性実証　mRNAがんワクチンで初、Moderna株一時2.6倍

参照元: 日本経済新聞 / 中日新聞（NY市場） / Reuters

米モデルナと米メルクは19日、悪性黒色腫（メラノーマ）患者を対象としたメッセンジャーRNA（mRNA）ワクチン「mRNA-4157/V940」の第3相臨床試験でメルクの既存免疫チェックポイント阻害剤keytrudaとの併用療法が「再発予防に統計的有意性」を実証したと発表。mRNAがんワクチンが後期治験で優位性を示すのは業界初となり、19日NY市場でModerna（MRNA）株は一時前日比2.6倍に急騰、Merck（MRK）も12%高となる場面があった。腫瘍抗原に基づく個別化mRNAワクチンとして規制当局への申請準備に入り、他がん種への展開も視野。トランプ政権下のRFK Jr.厚生長官による過去mRNAワクチン公費削減方針の中で、がん治療領域でのmRNA技術の有効性が改めて証明された歴史的マイルストーン。膵臓がん治療でも先行のmRNAワクチンが5割で腫瘍縮小を示すなど、mRNAプラットフォームの適応拡大が加速。

Charter Communications、$34.5B Cox買収完了　米ケーブル・広帯域最大手2社統合、Liberty Broadband合併も同時完結

参照元: The Hollywood Reporter (via Techmeme) / Bloomberg

Charter Communications（Spectrumブランド）は20日、2025年5月に発表したCox Communicationsの$34.5B（総額）買収を正式完了。同時に親会社Liberty Broadbandとの合併も完結し、米国最大の広帯域・ケーブル事業者が誕生した。統合後は約7,000万加入者・全米46州の広帯域網を保有、Netflix/Amazon Prime等ストリーミングやYouTube TVからの解約圧力に直面するケーブル業界の再編最終形となる。Charter/Coxはワイヤレス（MVNO）・企業向け・スマートホーム分野の共同投資で規模の経済を追求、Comcastに対抗する形で「fiber + wireless convergence」戦略を加速。Federal Communications Commission（FCC）の条件付き承認を6月に取得しており、米連邦通信規制の重要な先例ケースとなった。

参照元: Bloomberg (via Techmeme) / Techmeme River

米連邦債務、初の40兆ドル突破　トランプ・バイデン両政権下で10年で倍増、社会保障・利払い増と減税で歳入抑制

参照元: Reuters（Infoseek） / Bloomberg（Bloomberg Brief）

米財務省は19日、連邦政府債務総額が初めて$40Tを突破したと発表、18日時点は$40.047T。うち市場保有の米国債は$32.266T、政府内保有分は$7.782T。2017年1月のトランプ第1期就任時の$19.95Tから10年足らずで倍増、増加分の約1/3が新型コロナ対応の2年間緊急借入で、残りは両政権の恒常的な財政拡張と長年の歳入・歳出不均衡が積み重なった結果。ベセント財務長官は「長期債利回りを押し下げるため10-30年債バイバック規模を最低$40Bへ倍増」（前日既報）と発表、トランプ大統領は繰り返し利下げを要求。米国債の利払い費は既に国防予算を上回る水準に達しており、AI関連ハイパースケーラーの巨額社債発行（Alphabet・Amazon・Meta・Oracleで年初来$2,200億超）とも相まって、長期金利上昇が実体経済へ本格波及するリスクを孕む。「Bond Vigilantes（債券自警団）」の警戒感がPeter Bunkerの言葉通り再燃し始めた象徴的マイルストーン。

7月貿易収支▲6,345億円　3カ月連続赤字・輸出入額とも1979年以降最大、米国からの原油輸入量が9倍で史上最大

参照元: 日本経済新聞 / 時事エクイティ / 毎日新聞 / 連合ニュース（韓国）

財務省が20日発表した7月貿易統計速報によると、輸出入差額の貿易収支は▲6,345億円で3カ月連続赤字、赤字幅は前年同月の4倍。輸出額は11兆5,117億円（前年同月比+23.2%）で11か月連続プラス・過去最大、対米自動車・対中半導体電子部品の伸びが牽引。輸入額は12兆1,462億円（+27.8%）で6か月連続プラス・2か月連続過去最大、原油輸入額は1兆4,089億円（+87.8%）、通関ベースの原油単価は前年比+78.0%と急上昇（対イラン戦を受けたホルムズ海峡バイパスの代替調達コスト）。特に注目は米国からの原油輸入量が前年比9.1倍・金額15.9倍と1979年統計開始以来最大となった点で、対中東（-32.8%）からの本格シフトが数値で確認された。ドル円は米財務省バイバック倍増発表を受け158円台前半（前日の160円台から円高）で推移、貿易赤字拡大による構造的な円売り圧力と相殺する構図。
