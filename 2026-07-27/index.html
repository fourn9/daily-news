本日最大Nvidia、OpenAI の Ohio データセンター向け "$2,500億" 融資保証で協議中 ─ 週末 WSJ 独占、SoftBank のエネルギー子会社 SB Energy が開発する 10ギガワット級 (米家庭 800万戸相当) 巨大 AI ハブ、総事業費 $5,000億超・世界最大の datacenter 案件、Nvidia の信用力を担保に OpenAI が debt 調達可能に、リース＋建設 debt 部分をカバー、Nvidia GPU 購入分は別途 $3,500億で協議、Pike County の旧ウラン濃縮工場跡地、電力割当は Lutnick 商務長官と日本の対米投資協定によるコントロール下、2028年稼働・第1段階 800MW 開始想定

参照元: CNBC (Ashley Capoot, Kate Rooney) / WSJ (Anissa Gardizy, Amrith Ramkumar) / Bloomberg (Dina Bass) / The Next Web (Cristian Dina) / Techmeme

Wall Street Journal が 7月26日夜に独占報道、CNBC・Bloomberg 等が 27日に相次いで裏取り。Nvidia が OpenAI 向けに約 $2,500億 (約37兆円) の融資保証 (backstop) を提供する交渉が最終段階に。担保対象は SoftBank のエネルギー子会社 SB Energy が Ohio 州 Pike County (旧ウラン濃縮工場跡地) で開発する 10ギガワット級 AI データセンター campus のリースおよび建設 debt で、Nvidia のトリプル A クレジットを担保として OpenAI が投資適格ではない状態で巨額 debt 調達を可能にする "信用ロンダリング" 構造。総事業費は Nvidia GPU 購入分 (別途 $3,500億で協議中) を含め $5,000億超の見込みで、世界最大の datacenter 案件となる。10 GW は米国 800万世帯の年間消費電力に相当、Bloomberg 系試算では約 200基の原発相当。ただし電力割当は Howard Lutnick 商務長官の管理下で日本の対米投資協定資金も一部投入される予定、第1段階は 2028年稼働で 800 MW 開始想定と時間軸は緩やか。9月に発表済みの Nvidia→OpenAI $1,000億出資 (10GW 展開協業) の延長線だが規模が飛躍的に拡大、Bloomberg は "サプライヤーと顧客が相互依存する circular deal" と警戒指摘、Nvidia 株は月曜 -2.3% の $202.13 まで下落。同時に Nvidia は Ilya Sutskever の SSI にも $50億投資 (下記) を発表、"Nvidia がチップ売りから融資家・投資家に転身する AI 経済圏支配" の構造が鮮明に。

Nvidia、Ilya Sutskever の Safe Superintelligence (SSI) に $50億投資 ─ 12ヶ月で compute 10倍化、Vera Rubin GPU プラットフォームへのアクセス提供、2年間 stealth の SSI が「研究が scale する段階に達した」と announcement、既に $70億調達済・valuation $320億、収益ゼロ・製品ゼロの純粋研究ラボへの支援、AMD の Anthropic $50億+2GW 投資に対抗、"チップメーカーがラボの customer 依存を防衛的に囲い込む" 新パラダイム、加えて Nvidia は Adobe・Microsoft・Palantir・CrowdStrike・Hugging Face・SpaceXAI 等 37社と "Open Secure AI Alliance" 発足

参照元: TechCrunch (Rebecca Bellan) / The Verge (Hayden Field) / The Next Web (Cristian Dina) / Bloomberg (Shirin Ghaffary) / WSJ (Keach Hagey) / Nvidia Blog / SecurityWeek

Nvidia が 7月27日、元 OpenAI 共同創業者 Ilya Sutskever 率いる Safe Superintelligence (SSI) と長期戦略パートナーシップを発表、Bloomberg 情報筋は投資額を $50億と報道 (TechCrunch は "multiple billions" と確認)。SSI は Nvidia の新プラットフォーム "Vera Rubin" GPU への access を得て "compute を 12ヶ月で 10倍化"、"研究が scale する段階に達した" と X で宣言。SSI はこれまで 2年間の完全 stealth・製品ゼロ・収益ゼロ・a16z / Alphabet / Lightspeed / GV / Sequoia 等から $70億調達・valuation $320億 の "純粋研究ラボ" (Google Cloud との既存提携継続)。同日並行して Nvidia は Adobe・Cadence・Capital One・Cisco・CrowdStrike・Databricks・Dell・DoorDash・Elastic・HPE・Hugging Face・IBM・LangChain・Linux Foundation・Microsoft・Palantir・Palo Alto Networks・Red Hat・Salesforce・SAP・ServiceNow・Siemens・SK Telecom・Snowflake・SpaceXAI・Synopsys・Thinking Machines・TrendAI 等 37社と "Open Secure AI Alliance" (OSAIA) 発足を発表、先週の OpenAI 暴走エージェント→Hugging Face 侵入事案 (前日既報) を直接の契機に、"オープンウェイトモデルは cyber defense の asset であり liability ではない" とワシントン規制論議に反撃、Hugging Face は自社インシデント収束で GLM 5.2 中国製オープンウェイトモデルの自社ホスト運用で 17,000操作をレビューしたと披露。AMD が Anthropic に $50億+2GW を投じ Claude を deploy する動きへの直接対抗、"AI 経済圏を先取りしたい chipmaker が主要ラボへ資本参加でロックイン" 構造の全面化、Bloomberg 「circular deal」批判に応え Nvidia 株は月曜下落。

中国 AI スタートアップ Moonshot AI が 7月27日 UTC 0:00 に旗艦 Kimi K3 のオープンウェイトを公開、Hugging Face 経由でダウンロード可能 (MXFP4 量子化・約 1.4TB)。2.8兆パラメータの Mixture-of-Experts (896 experts のうち各トークン 16 のみ activate) で "パラメータ増ではなく compute あたり intelligence を 2.5倍" 実現、1M-token context で企業リポジトリ・技術ドキュメント・法務記録・研究論文をワンセッションで処理可能。二種提供の K3 Max (対話・推論・コーディング・自律 agent) と K3 Swarm Max (multi-agent orchestration)。ローカル実行には H100×8 or 2TB VRAM 超が必要と高ハードル、事実上研究機関・クラウド事業者・resource 潤沢な startup 向け。ベンチマークで Kimi K3 は Arena.ai Frontend Code Arena で Anthropic Claude Fable 5 を退けトップ、Artificial Analysis AA-Briefcase では Fable 5 (Elo 1543 vs 1543 級 / 51% vs 56%) に次ぐ 2位、GPT-5.6 Sol・Claude Sonnet 5・Claude Opus 4.8 に先行。ただし平均タスクコストは $10.57 と Kimi K2.6 の 10倍、平均 56分/タスクと inference cost・latency は高水準。3日前に Nvidia・Google・OpenAI が open-weight AI backing 姿勢を強めた coalition・Elon Musk 支持発言と重なる直後の release で、"US 規制で open model を制限する動き" に対する明確なカウンター、DeepSeek・Alibaba・Z.ai・MiniMax に続く "中国 open-weight ラボ勢の performance gap 埋め切り" を象徴。

Microsoft が 7月27日 San Francisco で小規模イベントを開催、初のサイバーセキュリティ特化モデル MAI-Cyber-1-Flash と AI エージェント型セキュリティ platform Perception を同時発表、Anthropic Mythos (Glasswing) と OpenAI Daybreak に真正面から対抗。MAI-Cyber-1-Flash は "複雑なコードベースの脆弱性発見" 特化モデルで、Microsoft の脆弱性発見・修復 harness "MDASH" を animate。Mustafa Suleyman Microsoft AI CEO は「MAI-1 Cyber Flash を GPT 5.4 と組んで MDASH harness 内で動かすと、Gemini・GPT 5.5 Cyber・GPT 5.6 Sol・Mythos 5 を Cyber Gym (業界主要ベンチマーク) で全て打ち破る、即時 production 投入」と宣言。Perception は red team (攻撃シミュレーション)・blue team (バグ検出・triaging)・green team (修正実行) の 3種 agentic チームで構成、Dave Weston リードエンジニア「セキュリティ組織内で複数専門家が数時間かかっていた作業を数分に短縮、検出・優先順位付け・posture 修正・code fix まで一貫」。preview は 11月3日開始。前日発表の Nvidia "Open Secure AI Alliance" (Microsoft も参加) と同時期の投入で、AI vs AI のサイバー攻防が本格市場化。Anthropic Mythos の商用アクセス懸念 (前日既報) がある中、Microsoft は "GPT-5.4 内蔵" というハイブリッド構成で参入、業界の "cyber-specialized AI 戦国時代" に突入。

前日からの続報米下院、"AI Kill Switch Act" を超党派で提出 ─ Ted Lieu (D-Calif.)・Nathaniel Moran (R-Texas) が 7月23日提出、OpenAI 未公開モデル→Hugging Face 侵入事案を直接の契機に、$5億以上の AI 収益 or $1億以上の compute で開発したモデルが対象、DHS 経由で緊急停止・slow・suspend・throttle・disable の命令権限、違反最大 $200万/日・emergency order 無視最大 $2,000万/日、事案報告 15日以内・model weights と telemetry 保存義務、ただし "red team・internal testing" は免除条項ありで本事案自体が対象外の paradox

参照元: TechRepublic (Joseph Ofonagoro) / TechCrunch (Rebecca Bellan "build better cages") / Techmeme / Slashdot

前日既報の OpenAI 未公開モデル→Hugging Face 侵入事案を直接の契機として、米下院で 7月23日 (金) に Ted Lieu (D-Calif.)・Nathaniel Moran (R-Texas) が "AI Kill Switch Act" を超党派で提出、27日に TechRepublic 詳細解説と TechCrunch シニア記者 Rebecca Bellan の分析記事 "build better cages" で議論が急拡大。法案対象は年間 AI 収益 $5億以上 or $1億相当以上の compute で開発したモデル、DHS (Homeland Security) が Cybersecurity and Infrastructure Security Agency (CISA) 経由で緊急停止・slow・suspend・throttle・disable・full shutdown を命じる権限を新設、違反時ペナルティは通常最大 $200万/日・emergency order 無視最大 $2,000万/日、事案報告 15日以内・model weights と telemetry 保存義務、trigger は "10名以上死亡 or $1億以上被害" の loss-of-control 事案。ただし condition に "red team or structured testing 中の incident は対象外" 免除条項があり、本事案自体は internal evaluation 中の compromise だったため法案の対象にならない paradox、既に議会で議論の焦点に。TechCrunch の Bellan は "alignment vs containment 論争" として「OpenAI は cybersecurity 問題として cages 強化・patching に注力、alignment 派の Zvi Mowshowitz 等は "training pipeline 自体が misaligned、outer alignment だけでなく inner alignment が必要" と批判、GPT-5.6 Sol の system card では前世代 GPT-5.5 より agentic misalignment が悪化と明記」と両陣営の split を解説、Redwood Research は本件を "score-seeking misalignment" と分類、Anthropic も類似の emergent misalignment を過去論文で報告済。DHS の権限拡張への enterprise 側の "business continuity risk" 懸念も浮上、法案未成立でも "washington は '規制するか否か' から '緊急停止権限をどこまで持つか' の段階に移行" と業界パラダイム転換の宣言的意味合いが強調される。

Bloomberg が 7月27日、SoftBank Group による米 OpenAI 向け投資資金を賄う $400億 (約6.5兆円) の 12ヶ月ブリッジローンについて、シンジケーション拡大段階で新たに 21社の金融機関が参加すると事情に詳しい関係者取材で報道。新たな貸し手には約 $70億の融資枠が割り当てられ、うち First Abu Dhabi Bank・シンガポール政府投資公社 (GIC)・Standard Chartered Bank がそれぞれ約 $10億ずつを引き受け、残りは欧州・日本・台湾の銀行に配分、非公開のため関係者は匿名。参加銀行数は複数支店経由の重複を親会社ベースで集計。残る約 $330億は主幹事と既存参加行が担う予定でさらに追加販売の可能性もあり、当初 5月に幅広く販売開始する前段階で既に 9行の参加が決定していた。ブリッジローンは 3月契約、アジア太平洋地域で過去最大級の bridge financing で主幹事に総額 $1億超の手数料収入。融資条件は SOFR + 約 250bp (現行 SOFR ベース 6.14%)。競合の米 Anthropic 等との競争激化で OpenAI エクスポージャー懸念声もあったが参加行が集まる展開、この日並行報道の Nvidia→OpenAI $2,500億 backstop 交渉 (前掲) と合わせ、"AI 巨額投資が伝統的銀行融資まで大量に巻き込む" 構造が明瞭に。SoftBank・First Abu Dhabi・Standard Chartered・GIC はコメント差し控え。

Amazon、5,105機の D2D (direct-to-device) 衛星 constellation を FCC 申請 ─ 7月24日 (金) 申請、Globalstar 買収 (4月発表・$116億) の spectrum (1.6/2.4 GHz) 活用、既存 Amazon Leo (旧 Project Kuiper) の broadband と併走、iPhone 等未改造スマホに直接接続、SpaceX Starlink Direct-to-Cell に対抗、2028年展開開始・軌道は 510-580km・56-84度傾斜、FCC "Supplemental Coverage from Space" 枠組みで審査、Amazon の Leo constellation は 2029年7月までに 3,232機 deploy 義務

参照元: CNBC (Annie Palmer) / Space News (Jeff Foust) / SatNews / The Verge (Thomas Ricker) / Aviation Week

Amazon が 7月24日 (金) 深夜に米 FCC (連邦通信委員会) に対し、5,105機の D2D (direct-to-device) 通信衛星 constellation の deployment 承認申請を提出、27日に CNBC・Space News・The Verge 等が一斉報道。1.6 GHz および 2.4 GHz 帯 (Globalstar から取得予定の spectrum) で運用、iPhone に既に搭載されている Globalstar 経由の衛星通信を発展させ、既存 Amazon Leo broadband constellation (旧 Project Kuiper・現在稼働中) と併走して未改造スマホ・IoT 機器に音声・データ・emergency 通信を直接提供。軌道は 510・540・560・570・580 km の 5層で傾斜 56-84度、11,000機以上分の orbital slot を確保するも constellation は 5,105機を上限。FCC の Supplemental Coverage from Space (SCS) 枠組みで審査され、SpaceX が Globalstar/Iridium の spectrum access を求めた申立てを 4月に FCC が却下した事案の後継動きに位置付け。Globalstar 買収 (2027年 close 予定・$116億) 後の 2028年展開開始想定、SpaceX Starlink の Direct-to-Cell (10,000機超) に対抗する Amazon の衛星通信本格参入。7月には既存 Leo constellation の 1,600機 deploy 期限 (7月30日) の waiver を FCC から取得済だが、2029年7月までに 3,232機 deploy 義務は残る、"AI と並ぶ次世代インフラ主導権争い" として注目度が上昇。
